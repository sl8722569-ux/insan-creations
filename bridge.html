INSAN Bridge

GitHub Pages cannot hold an API key or talk to ONVIF cameras. Bridge is a small Python server on this computer (port 8787). Apps call it for SpaceXAI, LAN cameras, and NEXCODE rooms. The key never goes in the website.

Start

  1. Copy bridge/.env.example to bridge/.env and paste XAI_API_KEY from console.x.ai.
  2. Run bridge/Open-INSAN-Bridge.bat and leave the window open.
  3. On this PC, apps auto-detect http://127.0.0.1:8787.
  4. On a phone (same Wi-Fi), set the bridge URL to the LAN address printed in that window, e.g. http://192.168.1.10:8787.

Bridge source on GitHub

What it unlocks

  • SpaceXAI — Mira, Vaani tutor, Study Assistant, NEXCODE AI (model grok-4.6).
  • UniVista cameras — paste RTSP or discover ONVIF; ffmpeg serves MJPEG.
  • NEXCODE pairing — 6-digit code maps to a live phone over PeerJS + this room list.
