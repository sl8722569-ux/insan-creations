J.A.R.V.I.S

J.A.R.V.I.S (Just A Rather Very Intelligent System) is a personal AI assistant you run yourself. It talks, listens when you allow the microphone, opens apps and websites, and helps with everyday Windows tasks. It is aimed at ordinary hardware — including Intel Core i3, 8 GB RAM, and HDD storage — with permissions off until you turn them on. This is Early Access: Phase 1 [EARLY ACCESS] and Phase 2 [EARLY ACCESS FINAL ACT].

Features

  • Wake phrase “Jarvis Activate” / “Jarvis Standby”
  • Voice + text chat; English, Hindi, Punjabi
  • Conversation follow-ups without repeating the wake phrase
  • Open apps, folders, sites, and web AIs (ChatGPT, Gemini…)
  • Notes, clipboard, timers, system info, gaming mode
  • Safe file helper; WhatsApp Web only after you confirm
  • Themes, layouts (full / sidebar / voice only)
  • Plugins: calculator, weather, translator, Steam & music helpers
  • Mic / speaker tests and voice diagnostics
  • Share the public project only — never your private files
