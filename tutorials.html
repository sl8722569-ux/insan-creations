HOW TO USE THE APPS

Tutorials

Two kinds of video for every product: 1. Talking (spoken steps) and 2. Showcasing (look at the real app). Turn on sound for talking videos. Showcasing is visual and silent.

1. J.A.R.V.I.S

1. Talking

2. Showcasing

  1. Open J.A.R.V.I.S on Windows, or the web app on a phone (Add to Home Screen).
  2. Say “Jarvis Activate”, or type in the chat box.
  3. Use English, Hindi, or Punjabi. Ask it to open apps, folders, or sites.
  4. Privacy stays off until you turn it on.

J.A.R.V.I.S page

2. AI Study Assistant

1. Talking

2. Showcasing

  1. Open the Study Assistant website from INSAN CREATIONS or GitHub.
  2. Choose the language you study in.
  3. Ask a question, request a plan, or practice a topic.
  4. Use Install / Add to Home Screen so it opens like an app.

Study Assistant page

3. UniVista

1. Talking

2. Showcasing

  1. Open UniVista Early Access from the official site.
  2. Privacy: allow camera. Enable snapshots only if you want local stills.
  3. Live view → Start camera.
  4. Snapshot, record, watch motion, or ask Mira.

UniVista page

4. Vaani

1. Talking

2. Showcasing

  1. Open Vaani Early Access. Add to Home Screen if you want an app icon.
  2. Catalogue: languages, scripts, varieties and transliteration are separate.
  3. Learn: meaning, script, reading, listen. Tap Hear it.
  4. Trace a glyph, or ask the on-device tutor.

Vaani page

5. NEXCODE

1. Talking

2. Showcasing

  1. Open NEXCODE Early Access. Files stay in this browser.
  2. Explorer or Ctrl+O → open app.js and type.
  3. Ctrl+Shift+P for the command palette.
  4. Host / Mobile is the same project, smaller chrome.

NEXCODE page

6. INSAN CREATIONS studio

1. Talking

2. Showcasing

  1. Open the INSAN CREATIONS website — the catalogue for every app.
  2. Browse All apps: J.A.R.V.I.S, Study Assistant, UniVista, Vaani, NEXCODE.
  3. Open a product page for downloads or launch.
  4. Watch that app’s talking tutorial or showcase.
