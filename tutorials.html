HOW TO USE THE APPS

Tutorials

Short videos for every app, plus the studio site. Turn on sound. Each video is about one minute and also written below.

1. J.A.R.V.I.S

  1. Open J.A.R.V.I.S on Windows, or the web app on a phone (Add to Home Screen).
  2. Say “Jarvis Activate”, or type in the chat box.
  3. Use English, Hindi, or Punjabi. Ask it to open apps, folders, or sites.
  4. Privacy stays off until you turn it on. Enable the microphone only when you want voice.

J.A.R.V.I.S page

2. AI Study Assistant

  1. Open the Study Assistant website from INSAN CREATIONS or GitHub.
  2. Choose the language you study in.
  3. Ask a question, request a plan, or practice a topic.
  4. Use Install / Add to Home Screen so it opens like an app.

Study Assistant page

3. UniVista

  1. Open UniVista Early Access from the official site.
  2. Privacy: allow camera. Enable snapshots only if you want local stills.
  3. Live view → Start camera. The browser will ask permission.
  4. Snapshot, record, watch motion, or ask Mira. Files stay on this device.

UniVista page

4. Vaani

  1. Open Vaani Early Access from INSAN CREATIONS or GitHub Pages. Add to Home Screen if you want an app icon.
  2. Catalogue: languages, scripts, varieties and transliteration are separate (Punjabi ≠ Gurmukhi).
  3. Learn: meaning, script, reading, listen. Tap Hear it. XP and streak stay on this device.
  4. Trace a glyph, or ask the on-device tutor. No AI keys in the page.

Vaani page

5. NEXCODE

  1. Open NEXCODE Early Access. Files stay in this browser.
  2. Explorer or Ctrl+O → open app.js and type. It saves here.
  3. Ctrl+Shift+P for the command palette (sessions, mobile, pairing demo).
  4. Host / Mobile switch is the same project, smaller chrome — not a second physical phone yet.

NEXCODE page

6. INSAN CREATIONS studio

  1. Open the INSAN CREATIONS website — the catalogue for every app.
  2. Browse All apps: J.A.R.V.I.S, Study Assistant, UniVista, Vaani, NEXCODE.
  3. Open a product page for downloads or launch.
  4. Install or download, then watch that app’s tutorial.
